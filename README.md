# simple_blog
Это пример блога на Django
в домашнем каталоге:

1. ```wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh```
2. ```bash Miniconda3-latest-Linux-x86_64.sh```
3. ```source /home/"имя пользователя"/miniconda3/bin/activate```
4. ```conda create -n djenv python=3.12```
5. ```conda activate djenv```
6. ```git clone git@github.com:alexandervashurin/simple_blog.git```
7. ```cd simple_blog/```
8. ```python -m pip install -r requirements.txt```
9. ```touch .env``` с реквизитами из ```settings.py```
